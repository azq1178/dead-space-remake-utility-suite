## 🚀 Installation & Setup Guide

Acquiring and initializing the suite is a process designed for zero downtime. We have streamlined the setup to be as efficient as the engineering tools on the Ishimura.

1.  **Acquisition:** Secure your copy via our partner network. Ensure you download the current build (v5.2.1 for 2026). The archive is named `DSRNexus_2026_x64.7z`.
2.  **Extraction:** After the download completes, use any standard archive utility (like 7-Zip or WinRAR) to extract the contents into a folder of your choice. We recommend keeping it in `C:\GameTools\` for simplicity.
3.  **Initialization:** Inside the extracted folder, locate the primary executable named `EnginePrime.exe`. Run it as an administrator to ensure proper access to system resources and the game process.
4.  **Bind & Launch:** Click the "Select Process" tab in the utility and navigate to your `DeadSpaceRemake.exe` file. After binding, start the game via the utility's "Engine Start" button. This ensures proper synchronization.
5.  **Verify:** The on-screen overlay should appear in the top-left corner within 3 seconds of the game loading into the main menu.

Using this suite is akin to conducting a symphony of chaos. The master faders you control are simple, but the effects are powerful.
